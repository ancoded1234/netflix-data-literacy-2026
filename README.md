# Netflix Data Literacy 2026

Public static presentation for a university data literacy assignment. Independent analysis; not an official Netflix presentation.

The 11-slide deck uses the official Netflix What We Watched H1 2026 report. All resources use relative paths and bundled fonts. Open index.html or serve this directory using python -m http.server 8000.

Raw workbooks, credentials, environments, intermediate datasets and screenshots are excluded. Only the three linked analysis/report files are included under assets/sources. Font licensing is included under assets/fonts/LICENSE.txt.

Official source: https://about.netflix.com/en/news/what-we-watched-the-first-half-of-2026
