# 넷플릭스의 인기는 소수의 콘텐츠에 집중될까?

공개된 개별 콘텐츠 행 기준으로 시청 시간은 소수 항목에 집중된다. 전체 상위 1%가 25.23%, 상위 10%가 67.93%를 차지하며 지니계수는 0.7899이다. 이는 원인 추정이 아닌 2026년 상반기 공개 분포의 기술적 설명이다.

## 대상과 분모

- 개별 17,370행: Movies 9,177행, Shows 8,193행. Other 2행은 개별 순위와 콘텐츠 수에서 제외.
- Shows는 시즌·리미티드 시리즈·개별 방송 등이 섞인 보고서 행 단위. 시리즈 전체 또는 영화 한 편과 같은 단위라고 주장하지 않음.
- A(개별 항목 사이 점유율): 해당 그룹의 개별 항목 시청 시간 합계. 지니계수·로렌츠 곡선도 이 분포만 사용.
- B(전체 시청 시간 대비 비중): A + 해당 그룹 Other 시청 시간. Other Movies/Other Shows의 귀속은 원본 시트·제목·각주로 확인.
- Runtime 별표 310행, 공개일 결측 11,324행 모두 유지. 공식 Hours Viewed와 Views 사용; 조회수 재계산·보간 없음.

## 평균·중앙값과 지표별 순위 차이

평균은 영화 2,528,855시간(중앙값 500,000), 시리즈·방송 8,982,949시간(중앙값 2,300,000)이다. 평균이 중앙값의 각각 5.06배, 3.91배로, 평균 하나로 전형적인 항목을 설명하기 어렵다.

인기 순위는 지표에 따라 다르다. 시청 시간·조회수 TOP 10의 겹치는 항목은 영화 9개, 시리즈·방송 8개다. 시청 시간은 소비 시간 총량, 공식 Views는 길이를 반영한 지표이며 고유 시청자 수가 아니다.

- Movies: 시청 시간 1위 **War Machine**, 공식 조회수 1위 **War Machine**. 공식 조회수는 시청 시간 총량과 다른 기준이다. 긴 항목은 같은 조회수에서도 시청 시간이 커질 수 있으나, 이번 비교만으로 길이가 순위 차이의 유일한 원인임을 입증하지는 않는다.
- Shows: 시청 시간 1위 **Bridgerton: Season 4**, 공식 조회수 1위 **His & Hers: Limited Series**. 공식 조회수는 시청 시간 총량과 다른 기준이다. 긴 항목은 같은 조회수에서도 시청 시간이 커질 수 있으나, 이번 비교만으로 길이가 순위 차이의 유일한 원인임을 입증하지는 않는다.

## 공식 발표와 합계 대조

- 개별 시청 시간 96,804,600,000시간 + Other 859,900,000시간 = **97,664,500,000시간(976.645억 시간)**.
- [공식 발표](https://about.netflix.com/en/news/what-we-watched-the-first-half-of-2026)의 970억 시간 초과라는 설명과 일치한다. 970억보다 664,500,000시간 많지만, 발표는 정확히 970억이라고 한 것이 아니므로 불일치가 아니다.
- 합계는 공개 반올림 값의 합산이며 내부 비반올림 총계와 정확히 동일하다고 보장할 수 없다.
